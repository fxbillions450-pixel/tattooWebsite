# Wizards Tattoos branding

The user-requested website name is Wizards Tattoos. The original profile image was retrieved from the public https://www.instagram.com/wizardstattoos/ account (display name: Wizards Studio). The logo artwork itself is retained without redrawing, recoloring, or changing its lettering.

The available image is a 150 x 150 JPEG, stored in `assets/wizards-instagram-logo.jpg` and embedded at build time in the header, loading screen, and favicon. Visitors do not request it from Instagram. SHA-256: `b7962b05663cd7af62b3f62e2e669c847b35de3157d944b58b33a156b7a4623b`.

`src/brand.css` contains only the branding layout adjustments. The original stylesheet, 3D mesh, renderer, artwork generator, motion controller, scroll handler, and navigation application are unchanged from commit `3c208aecd51ce87588c2b8faae311c23f706fcef`.

Run `python3 tools/build.py` before opening or sharing the generated root/public HTML snapshots. Vercel runs this build on every deployment. Do not hotlink the expiring Instagram CDN address.

The booking form remains a demonstration; the name change does not connect real bookings or replace concept copy/portfolio artwork with the studio's actual work.
